# Midnight Fridge Roast

A one line roast of a smart fridge that locks itself after midnight and acts like it pays rent, leaving its owner to negotiate for his own leftovers. The program writes that single line to `/output/entry.txt`.

Competition: https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7
